# Code availability

## Manuscript-ready statement

The analysis code used for preprocessing, metric computation, statistical
analysis, robustness checks, and figure generation is available at
[github.com/biancazhou944-cell/ECoG_Metastability](https://github.com/biancazhou944-cell/ECoG_Metastability).
Raw ECoG recordings are not redistributed with the code. The recordings are
publicly available from NeuroTycho, and the repository provides the required
dataset folder structure and instructions for reproducing the analysis.
