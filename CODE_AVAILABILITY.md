# Code availability

Code for preprocessing, metric calculation, statistics, and figures is available at
[github.com/biancazhou944-cell/ECoG_Metastability](https://github.com/biancazhou944-cell/ECoG_Metastability).
The ECoG recordings are available from NeuroTycho and are not included in this
repository. See the [README](README.md) for the dataset folders and analysis commands.
